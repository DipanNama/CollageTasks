Pick prefix or postfix, then follow the statements.

A single printf is a different problem.printf("%d %d %d", i, ++i, i++);

The original assignment included this expression. In C it has unsequenced reads and modifications of i: undefined behavior. There is no guaranteed output to predict. This lab only shows separate, sequenced statements.

Prefix: update first

In j = ++i, increment i, then assign the new value to j.

Postfix: use the old value

In j = i++, j receives the old value. i has increased by the end of the statement.
